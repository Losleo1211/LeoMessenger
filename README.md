# 🦁 Leo's Messenger

Ein schlanker SMS-Messenger für Android mit einer Funktion, die mir bei vielen anderen Messenger-Apps fehlt:

> **Texte und beliebige Teile einer SMS können frei markiert und kopiert werden.**

## 📱 Aktuelle Version

**V1.0.11**

## ✨ Funktionen

- 📤 SMS senden
- 📥 SMS empfangen
- 📚 Vorhandene SMS vom Smartphone importieren
- 👤 Zuordnung der SMS zu Kontakten
- 💬 Übersichtliche Chat-Darstellung
- 🔎 Chats durchsuchen
- 📞 Telefonnummern direkt aus dem Chat verwenden
- ✏️ Kontakte bzw. Chats bearbeiten
- 🗑️ Chats löschen
- 📋 Beliebige Textstellen einer Nachricht markieren und kopieren
- 💾 Nachrichten bleiben lokal auf dem Smartphone gespeichert
- 📱 Verwendung als Standard-SMS-App unter Android
- 🦁 Eigenes Leo's-Messenger-App-Icon

## 🎯 Warum Leo's Messenger?

Bei verschiedenen SMS-Apps ist es nicht oder nur umständlich möglich,
einen bestimmten Teil einer Nachricht zu markieren und zu kopieren.

Leo's Messenger wurde deshalb mit einem besonderen Schwerpunkt entwickelt:

**Nachricht öffnen → gewünschten Text markieren → kopieren.**

## 🔐 Datenschutz

Leo's Messenger ist als klassischer SMS-Messenger konzipiert.

Nachrichten werden über die SMS-Funktion des Smartphones gesendet und
empfangen. Für die benötigten Funktionen verwendet die App die
entsprechenden Android-Berechtigungen.

## 🛠️ Entwicklung

- Android
- Kotlin
- Jetpack Compose
- Android Studio

Entwickelt und getestet unter anderem auf einem **vivo X300**.
